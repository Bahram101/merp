# CLAUDE.md

Инструкции для Claude Code при работе в этом репозитории (merp / Aura).

## Качество кода

Всегда писать чистый код, следуя принципам разработки (DRY и другим). Код не должен дублироваться.

- Если в проекте уже есть готовый компонент — использовать его, а не писать заново.
- Если готового компонента нет — создавать новый, аккуратно.
- Не писать "мусорный" (небрежный, одноразовый) код.
- Перед созданием нового компонента/функции — сначала искать существующий аналог в кодовой базе.
- При создании нескольких похожих файлов (например, экранов по одному паттерну) — сразу выносить дублирующиеся константы/логику в общее место, не дожидаясь замечания.

## Workflow: /agy

Задачи, подходящие под `/agy`, выполнять через него. Agy сначала расходует лимитную/бесплатную квоту (Antigravity — Argon, Flash, Claude, GPT и т.д.), и только потом переключается на другие источники.

После того как агенты agy выполнили работу — самостоятельно проверять результат (просматривать изменённые файлы/диффы) перед тем как считать задачу завершённой.
